# 1장 처음 만나는 코덱스

## [실습 01] 틱택토 게임 만들기

[tic-tac-toe](tic-tac-toe/) 폴더에는 Codex CLI로 만든 완성본이 들어 있습니다.

- `index.html`: 외부 라이브러리 없이 파일 하나로 실행되는 틱택토 게임
- `AGENTS.md`: `/init`으로 만든 프로젝트 규칙 초안

### 실행 방법

`index.html`을 더블 클릭해 브라우저로 엽니다. 개발 서버가 필요 없습니다.

### 플랜 모드에서 보낸 요청

Shift+Tab 또는 `/plan`으로 플랜 모드를 켠 뒤 보냅니다.

```text
현재 폴더에 브라우저에서 실행하는 틱택토 게임을 만들고 싶어. 먼저 구현 계획만 제안해줘.
두 사람이 한 화면에서 번갈아 플레이하고 X가 먼저 시작하게 해줘. 빈칸에만 표시할 수 있어야 해. 가로, 세로, 대각선 세 칸이 같으면 승리이고, 승자 없이 아홉 칸이 차면 무승부야. 게임이 끝난 뒤에는 더 놓을 수 없어야 해.
현재 차례와 결과를 한국어로 보여주고, 다시 시작 버튼을 넣어줘. 외부 라이브러리나 인터넷 연결 없이 index.html 하나를 열어 실행할 수 있게 해줘. 휴대전화에서도 게임판이 화면 밖으로 나가지 않아야 해. 확인할 항목도 계획에 포함해줘.
```

### 검증 순서

칸 번호는 왼쪽 위부터 오른쪽 아래까지 1~9번입니다. 항목마다 [다시 시작]을 누르고 시작하세요.

```text
1 | 2 | 3
4 | 5 | 6
7 | 8 | 9
```

| 확인 항목 | 클릭 순서 | 기대 결과 |
|---|---|---|
| 가로 승리 | 1 → 4 → 2 → 5 → 3 | X 승리(위쪽 가로줄) |
| 세로 승리 | 1 → 2 → 4 → 3 → 7 | X 승리(왼쪽 세로줄) |
| 대각선 승리 | 1 → 2 → 5 → 3 → 9 | X 승리 |
| 반대 대각선 승리 | 3 → 1 → 5 → 2 → 7 | X 승리 |
| O의 승리 | 1 → 4 → 2 → 5 → 9 → 6 | O 승리(가운데 가로줄) |
| 무승부 | 1 → 2 → 3 → 5 → 4 → 6 → 8 → 7 → 9 | 무승부 |
