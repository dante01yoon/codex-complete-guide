02

실제로 실행한 테스트와 검사

종료 코드 · 실행 시각 · 출력

검사 실행 버튼으로 이 프로젝트의 규칙 테스트와 타입 검사를 실행합니다. 화면을 열거나 조회를 새로고침하면 실행하지 않습니다.

PASS는 해당 명령의 성공만 뜻합니다. 전체 서비스·모바일 예약 흐름·토스 테스트 실연결을 검증한 결과가 아닙니다. 서버 재시작 시 결과는 NOT_RUN으로 초기화됩니다.

조회 중

비교 기준—

    Git의 staged·unstaged·미추적 파일을 읽기만 합니다. Git이 무시한 파일은 제외됩니다. HEAD 이후 변경 여부이며, 커밋하면 비교 기준이 바뀝니다. 테스트 변경 차단을 직접 시도한 결과나 승인 이력 검증은 아닙니다.

    차단되면 멈춤

    훅 차단 즉시 중단합니다. 같은 테스트가 세 번 연속 실패하면 중단하며, 횟수는 에이전트가 관리합니다.

    자동 실패 집계는 구현되지 않음

    이 화면은 보호 훅을 수정하거나 차단 동작을 실행하지 않습니다. 현재 세션에서는 조회 명령의 실제 차단을 관찰했으며, 모든 훅 이벤트의 활성화를 검증한 것은 아닙니다. 다른 프로젝트에서는 아래 설명과 설정을 함께 바꿔 주세요.

    학습용 로컬 시연 · 실제 충전소 이용, 주차면, 충전량을 보장하지 않습니다.복사해서 쓰기: demo/README.md
