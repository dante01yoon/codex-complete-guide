# 하네스 확인 화면

Node.js 24만 필요하며 demo 자체의 npm 설치나 빌드는 없습니다.
프로젝트 루트에서 실행합니다.

```sh
node demo/server.mjs
```

http://127.0.0.1:4174 에서 확인합니다. 서버는 로컬 주소에만 바인딩합니다.
종료는 실행한 터미널에서 Ctrl+C를 누릅니다.

## 다른 폴더에 복사

1. 대상 프로젝트의 루트에 demo 폴더 전체를 복사합니다.
2. config.mjs에서 프로젝트 이름과 검사 명령 배열을 맞춥니다.
   실행할 검사가 없으면 command를 null로 설정하면 NOT_RUN을 표시합니다.
3. adapter.mjs를 대상 프로젝트의 공개 순수 함수에 연결합니다.
   환불 정책을 화면에 중복 구현하지 않습니다. 모듈이 없으면 BLOCKED를 표시합니다.
4. index.html의 프로젝트별 정책 설명·예시 날짜·하네스 설명을 맞춥니다.
   현재는 ev-booking의 3,000원 예약금과 AC-07-1~3 예시입니다.
5. node demo/server.mjs로 실행합니다. 기존 서버가 있다면 먼저 종료합니다.

다른 위치의 프로젝트를 읽으려면 DEMO_PROJECT_ROOT 환경 변수에 Git 저장소
루트의 절대 경로를 지정합니다. 이 값은 프로세스 시작 시에만 읽습니다.
HTTP 요청으로 검사 명령이나 경로를 변경할 수 없습니다.

## 무엇을 확인하는가

- 환불: 기존 src/rules/refund.ts의 reduceUserCancellation 호출 결과입니다.
  환불과 승계 요청을 외부에서 실행하지 않습니다. 금액은 KRW 정수,
  시각은 명시적 +09:00 예시를 사용합니다. 전체 AC-07-4~5·결제 연결 검증은 아닙니다.
- 검사: config의 명령을 shell 없이 순서대로 실행합니다. 결과는 메모리에만
  보관하며 재시작 시 NOT_RUN입니다. 실패나 시간 초과도 성공으로 바꾸지 않습니다.
  설정된 명령 자체는 신뢰하는 로컬 명령이어야 합니다.
- tests: Git HEAD 대비 staged·unstaged·미추적 파일을 git status로 읽습니다.
  Git 저장소 루트와 HEAD가 없으면 BLOCKED입니다. Git 무시 파일은 제외하며,
  커밋 후에는 비교 기준이 새 HEAD로 바뀝니다. 승인된 테스트의 별도 기준 해시나
  커밋된 과거 테스트 변경을 검사하는 기능은 아닙니다.
- 하네스: 문서의 역할과 보호 장치 범위를 설명합니다. 차단을 시험하기 위해
  테스트를 변경하거나 훅을 끄지 않습니다. 설정 존재는 실제 이벤트 활성화의 증거가 아닙니다.

PASS / FAIL / BLOCKED / NOT_RUN은 각 검사별 상태입니다. tests 변경 있음은
조회 성공 뒤의 관찰 결과이며, 파일 수정의 정당성을 자동 판정하지 않습니다.
출력은 일반적인 인증·결제 키 형식을 가리고 최대 24,000자로 제한합니다.
실행 출력에 사용자 정의 비밀값을 출력하는 명령을 설정하지 마세요.

## 화면 검증

```sh
node --test demo/acceptance.test.mjs
```

승인된 검증은 기존 환불 경계, 실제 명령의 상태 분류, 임시 저장소의
tests 변경 감지 및 조회 불변성을 확인합니다. 다른 정책의 프로젝트로
복사하면 검증도 그 프로젝트에 맞는 별도 확인 단계가 필요합니다.
