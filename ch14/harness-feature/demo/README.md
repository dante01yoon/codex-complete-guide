# 하네스 확인 화면

프로젝트 루트에서 `node demo/server.mjs`를 실행하고 <http://127.0.0.1:4174>를 엽니다.
포트 변경: `PORT=4175 node demo/server.mjs`. 서버는 항상 `127.0.0.1`에만 바인딩합니다.
종료는 Ctrl+C입니다.

`demo` 폴더 전체를 다른 프로젝트 루트에 복사해 같은 명령으로 실행할 수 있습니다.
셸의 현재 폴더가 아니라 `demo`의 상위 폴더를 검사합니다. 필요한 환경은 다음과 같습니다.

- Node.js 24, npm, Git 및 HEAD 커밋
- 기존 의존성 설치 완료, `package.json`의 `test:rules`가 Vitest 실행 명령
- `src/rules/refund.ts`가 `reduceUserCancellation(state, event)`를 내보내는 기존 인터페이스
- 비교할 `tests` 폴더

환불은 기존 함수의 반환 상태에서 읽습니다. 환불 정책을 복사하거나 하드코딩하지 않습니다.
서울 시간 2026-10-06 14시 시작 예약을 지정된 일곱 시점에 각각 취소합니다.
새로고침 때 현재 환불 소스와 Git 변경 상태를 다시 읽습니다.

테스트는 서버 시작 시 기존 `npm run test:rules`에 Vitest JSON 리포터 옵션만 추가하여 한 번 실행합니다.
리포트는 OS 임시 폴더에 생성한 뒤 삭제하며 기존 소스·테스트·설정을 수정하지 않습니다.
테스트 결과는 시작 시점의 기록입니다. 소스 변경 후 테스트를 재실행하려면 서버를 재시작하세요.
실패한 테스트 개수가 0이어도 수집 오류·비정상 종료는 PASS로 표시하지 않습니다.
실행 실패 또는 보고서 누락은 BLOCKED이며 개수를 0으로 꾸미지 않습니다.

테스트 파일 비교는 HEAD 대비 현재 상태이며 staged/unstaged 변경과 미추적 파일(ignored 포함)을 확인합니다.
수정·추가·삭제가 있으면 FAIL(변경 감지), Git/HEAD 확인 불가는 BLOCKED입니다.
이는 테스트 보존에 대한 관찰 결과이며 도구 실행 차단이나 훅 신뢰 등록을 증명하지 않습니다.
이미 커밋된 테스트 변경은 새 HEAD의 일부이므로 변경 없음으로 나옵니다.

관련 정책: US-07, AC-07-1~3, T-22. 기존 규칙을 관찰하며 제품 기능·정책을 추가하지 않습니다.
실제 결제·환불·충전소 이용 또는 외부 배포는 수행하지 않습니다.
