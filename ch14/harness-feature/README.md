# harness-feature: 하네스로 기능 만들기

『코덱스 완벽 가이드』 14장 [실습 14] '하네스로 기능 만들기'(08~10단계)를 마친 상태입니다. 06단계의 하네스 확인 화면(`demo/`)이 들어 있는 `harness-on`에서 시작해, 코덱스가 자기 화면을 보는 도구와 맞춤 린트를 만들고 그 위에서 '내 예약' 화면을 만들었습니다. 챗GPT 앱(macOS)과 GPT-6.1-Sol(medium), 권한은 Full access로 진행했습니다. 작성 기준일은 2026년 10월 11일입니다.

| 파일 | 내용 |
|---|---|
| `scripts/dev.mjs`, `web/` | `npm run dev`. Node.js 내장 서버로 화면을 띄웁니다(127.0.0.1:4173) |
| `scripts/check-ui.mjs`, `docs/ui-check.md` | `npm run check:ui`. Playwright로 휴대폰·데스크톱 크기 스크린샷을 찍고 콘솔 오류와 서버 로그를 요약합니다 |
| `scripts/ui-lint.mjs`, `scripts/lint-ui.mjs`, `docs/ui-lint.md` | `npm run lint`. 화면 코드에서 금액·시간을 계산하거나(EV002) 기기 현재 시각을 쓰면(EV001) 위치·이유·고치는 법을 출력합니다. `npm run check:lint`는 린트 자체 검증 |
| `src/server/`, `specs/my-reservations-*` | 내 예약 화면의 서버와 시연 예약 세 건, 설계·검증 테스트·검증 기록 |
| `demo/` | 06단계 하네스 확인 화면(`node demo/server.mjs`, 4174) |

## 실행

```sh
npm ci
npx playwright install chromium
npm run dev          # http://127.0.0.1:4173
npm run check:ui
npm run lint
```

- 시연 예약 세 건은 화면 시연 전용입니다. 운전자당 1건 제한과 정각·30분 시작 제한의 예외이며, 취소·환불은 서버 메모리의 모의 처리입니다. 실제 토스 환불이 아닙니다.
- 훅(`.codex/hooks.json`)은 앱의 [Settings > Hooks]에서 신뢰해야 동작합니다. `hooks.json`은 `git rev-parse --show-toplevel`로 경로를 찾으므로 이 폴더를 따로 꺼내 `git init` 후 사용하세요.

## 보낸 요청

### 08단계

```text
이제 화면을 붙일 건데, 그 전에 네가 만든 화면을 직접 보고 확인할 수 있는 도구부터 만들어 줘. 서버를 띄우는 npm run dev랑, 휴대폰·데스크톱 크기로 스크린샷을 찍고 콘솔 오류와 서버 로그를 요약해 주는 npm run check:ui면 돼. 아직 기능 화면은 만들지 말고 빈 화면으로 확인만 하고 커밋해 줘.
```

도구 구성을 확인해 달라고 했을 때의 답:

```text
좋아, 그 구성으로 진행해 줘.
```

### 09단계

```text
화면 코드가 지킬 규칙을 린트로 만들어 줘. 금액이랑 시간 계산은 src/rules에서만 하고, 현재 시각은 서버에서 받은 걸 쓰게. 어기면 어디가 왜 문제고 어떻게 고치면 되는지 네가 읽고 바로 고칠 수 있게 알려 주면 좋겠어. 다 되면 커밋해 줘.
```

### 10단계

```text
이제 운전자가 쓰는 '내 예약' 화면을 만들어 줘. 예약마다 지금 취소하면 얼마 돌려받는지, 시작까지 얼마 남았는지 보여 주고, 취소는 확인 받고 모의로 처리해. 시연용 예약은 2시간 넘게, 1시간, 20분 남은 걸로 세 개 만들어 줘. 시연용이니까 1건 제한이나 정각·30분 규칙은 예외로 해도 돼. 다 만들면 직접 화면 보고 확인해.
```

헌법대로 설계와 검증 테스트를 먼저 쓰고 확인을 요청했을 때의 답:

```text
확인했어. 그대로 진행하고, 다 되면 커밋한 다음 화면에서 뭘 보고 뭘 고쳤는지 정리해 줘.
```
