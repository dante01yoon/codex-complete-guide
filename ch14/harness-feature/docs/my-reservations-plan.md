# 내 예약 화면 — 구현과 검증 기록

2026-10-11. 관련 작업: T-21·T-23·T-24의 화면 시연 부분. 사용자 요청으로 서버 메모리·모의 취소 범위를 확정했으며, 로그인·토스·대기 승계·체크인 구현은 포함하지 않는다.

## 화면·서버 구성

- 기존 Node HTTP 서버(`scripts/dev.mjs`)와 `ui/index.html`을 사용한다.
- 서버의 고정 시연 시각은 서울 2026-10-11 10:00:00이다. 12:30~13:30, 11:00~12:00, 10:20~11:20의 가상 예약을 별도 시연 저장소에 둔다. 충전소 이름·충전기 식별자는 가상 시연용임을 표시한다.
- 이 고정 시계에서는 남은 시간 표시를 시연 입력값인 2시간 30분·1시간·20분으로 서버가 제공한다. 화면은 시각을 얻거나 시간을 계산하지 않는다. 시계 진행 기능은 추가하지 않는다.
- 예상 환불은 `reduceUserCancellation`에 저장 상태의 사본과 서버 시연 시각을 전달해 얻는다. 조회는 저장 상태를 변경하지 않는다.
- 취소 확인 전에는 요청하지 않는다. 확인 후 서버에서 같은 함수로 취소하고 양수 환불 효과에 대해서만 모의 `refund-succeeded` 이벤트를 반영한다. 반복 요청에는 최초 결과를 유지한다. 승계 효과는 실행하지 않는다.
- 확정 목록과 취소 결과를 구분하고, 새로고침 후에도 서버 메모리의 취소 결과를 유지한다. 서버 재시작 시 시연 자료를 다시 만든다.
- 화면에 시연 데이터, AC-03-2·AC-04-2 예외, 실제 토스 환불 아님, 실제 충전소 이용·주차면·충전량 보장 없음 안내를 둔다.
