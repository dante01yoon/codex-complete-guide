# 전국 도서관 지도

HTML, CSS, JavaScript로 만든 한 페이지 웹앱입니다. 외부 라이브러리는 MapLibre GL JS 5.24.0만 CDN에서 불러옵니다. 배경 지도는 OpenFreeMap Liberty 벡터 타일을 사용하며 확대 시 OpenMapTiles 건물을 3D로 표시합니다. 차트는 CSS로 직접 표시합니다.

프로젝트 루트에서 실행:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory web
```

http://127.0.0.1:8765 에서 엽니다. 실행 중인 앱은 저장된 JSON만 읽으며 MCP 서버에 다시 요청하지 않습니다. 지도 라이브러리와 배경 타일에는 인터넷 연결이 필요합니다.

## 데이터 수집

`web/data/`는 저장소에 포함하지 않습니다. library-mcp를 챗GPT 앱에 등록한 뒤 책 06.5의 프롬프트로 코덱스에게 데이터를 모으게 하면 같은 파일이 만들어집니다. 만든 웹앱은 내 컴퓨터에서만 실행하고 배포하지 마세요.

`data/libraries.json`은 등록된 library-mcp MCP 도구의 실제 응답에서 저장한 데이터입니다. CSV를 직접 파싱하거나 다른 데이터 소스를 사용하지 않았습니다. 집계와 검색 요약을 저장하고 상세 응답에서 위도·경도·데이터기준일자를 결합했습니다.

| MCP 도구 | 호출 수 | 목적 |
| --- | ---: | --- |
| stats_by_region | 1 | 전국 및 시도별 집계 |
| search_libraries | 38 | 구조 확인 1회, 100행씩 전체 37페이지 |
| get_library | 3,602 | 상세 구조 확인 1회, 전체 3,601행의 좌표·기준일 조회 |
| 합계 | 3,641 | 모든 호출 성공 |

조회일은 2026-10-03이며 원본 기준일은 2018-05-01 ~ 2026-08-26입니다. 정확한 인자와 조회 ID는 `data/tool-calls.json`에 기록됩니다.

전국 3,601행, 자료수(도서) 149,043,414권, 원본 시도 표기 18개입니다. 동일 이름의 원본 행은 각각 유지합니다. 전라남도와 전남광주통합특별시도 별도 원본 집계입니다. 좌표가 없거나 잘못된 104행은 검색·통계에 포함하며 지도에서는 제외합니다. 유효 좌표는 3,497행입니다.

## 사용

- 두 차트는 각 지표가 많은 순서이며, 막대를 누르면 시도 필터가 선택됩니다.
- 시도 필터는 원본 시도명의 정확한 일치로 적용합니다.
- 도서관 이름 검색은 앞뒤 공백을 제거하고 부분일치로 적용합니다. 시도와 검색어를 함께 적용할 수 있습니다.
- 결과 목록은 페이지당 20행입니다. 결과 클릭 시 해당 3D 기둥으로 부드럽게 이동하고 이름·주소·장서·기준일 팝업을 엽니다.
- 지도 CDN 또는 타일 실패 시 안내를 표시합니다. 검색 및 차트는 계속 사용할 수 있습니다.


## 3D 지도

도서관 기둥은 장서 수에 정확히 비례하여 1권당 0.002m(1만 권당 20m) 높이로 표시합니다. 이는 데이터 시각화 높이이며 실제 건물 높이가 아닙니다. 화면의 가독성을 위해 기둥의 바닥 반경만 확대 수준에 따라 22~1,600m로 바뀝니다. 전국 수준에서는 위치 점도 함께 표시합니다. 장서가 0인 도서관은 기둥 높이가 0입니다.

건물은 Liberty 스타일의 `building-3d` 레이어로 확대 수준 14 이상에서 표시하며 타일의 `render_height`와 `render_min_height`를 사용합니다. 원본 JSON은 변경하지 않았고 추가 MCP 조회도 하지 않았습니다.

시도 선택 시 해당 결과의 좌표 범위로 1.4초 동안 비행합니다. 결과를 누르면 확대 수준 15.5, 기울기 60도로 이동합니다. 기울기·회전 버튼, 우클릭 드래그, 모바일 두 손가락 제스처를 지원합니다. OS의 동작 줄이기 설정을 따릅니다. 지도 하단에는 OpenFreeMap, OpenMapTiles, OpenStreetMap 출처를 항상 남깁니다.

참고: https://openfreemap.org/quick_start/ 및 https://maplibre.org/maplibre-gl-js/docs/API/classes/Map/
