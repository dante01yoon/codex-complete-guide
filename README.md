# 『코덱스 완벽 가이드』 2판 실습 자료

책의 실습에서 사용한 파일과 설정 예시, 요청 프롬프트를 장별로 모아 둔 저장소입니다.
책을 따라 하다가 결과가 다르거나 파일이 필요할 때 이곳의 자료와 비교해 보세요.

## 실습 환경

- 작성 기준일: 2026년 10월 2일
- 챗GPT 데스크톱 앱(macOS), Codex CLI 0.159.2(1장) / 0.160.0(2~4장)
- 같은 요청을 입력해도 모델과 버전에 따라 코덱스의 답변과 코드는 조금씩 달라질 수 있습니다.

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| [ch01](ch01/) | 1장 처음 만나는 코덱스 — [실습 01] 틱택토 게임 완성본과 요청 프롬프트 |
| [ch02](ch02/) | 2장 나에게 맞는 코덱스 작업 환경 설정하기 — 설정 파일 예시와 요청 프롬프트 |
| [ch03](ch03/) | 3장 코덱스 사용 요금과 사용량 알아보기 — 사용량 확인 명령과 비교 실험 |
| [ch05](ch05/) | 5장 코덱스와 더 정확하고 효율적으로 일하기 — AGENTS.md, 메타 프롬프트, 습관 트래커 |
| [ch04](ch04/) | 4장 코덱스 CLI 고급 기능 활용하기 — 프로필, 훅, codex exec, PR 사전 검사, 3D 레이싱 게임 |

## 사용 방법

1. 이 저장소를 내려받거나 필요한 파일만 복사합니다.
2. 책의 실습 폴더(`~/Documents/codex-practice`)에 파일을 넣고 코덱스를 실행합니다.
3. 설정 파일 예시는 각 파일 맨 위의 주석에 적힌 위치로 복사해서 사용합니다.

로그인 정보(`~/.codex/auth.json`)처럼 개인 정보가 담긴 파일은 이 저장소에 올리지 마세요.
