# OVAL CLUB

Three.js로 만든 브라우저 3D 타임 어택 레이싱 게임입니다. 노을빛 타원형 트랙에서 세 바퀴를 달려 최고 랩 기록에 도전하세요.

화면은 밝은 배경·패널과 어두운 글자의 인쇄용 테마입니다. 카운트다운, 미니맵, 일시정지·결과 창에도 같은 대비를 적용했습니다. 브라우저 인쇄 시 A4 가로 한 페이지에 맞추며, 원하는 장면을 일시정지한 뒤 인쇄하거나 화면을 캡처할 수 있습니다.

## 실행

프로젝트 폴더에서 정적 웹 서버를 실행합니다.

```sh
python3 -m http.server 8000
```

브라우저에서 **http://localhost:8000**에 접속합니다. 설치나 빌드는 필요하지 않습니다. `index.html`을 직접 여는 `file://` 방식 대신 웹 서버를 사용하세요.

Three.js **0.180.0**을 jsDelivr CDN에서 불러오므로 인터넷 연결과 WebGL 2를 지원하는 데스크톱 브라우저가 필요합니다. Google Fonts를 사용할 수 없으면 시스템 글꼴로 표시됩니다. 외부 이미지나 3D 모델은 사용하지 않습니다.

## 조작

| 키 | 동작 |
| --- | --- |
| W / ↑ | 가속 및 경기 시작 |
| S / ↓ | 브레이크 (후진 없음) |
| A / ← | 왼쪽 조향 |
| D / → | 오른쪽 조향 |
| P / Esc | 일시정지 / 계속 달리기 |
| R | 처음부터 다시 시작 |

화면 위 버튼으로도 일시정지와 재시작을 할 수 있습니다. 다른 창이나 탭으로 이동하면 자동으로 일시정지하며, 돌아온 뒤 직접 재개합니다.

## 경기 규칙

- 처음 W 또는 ↑를 누르면 화면 중앙에 3 → 2 → 1이 각각 1초씩 표시됩니다. 카운트다운 중에는 차량과 랩 타이머가 멈추고, 끝난 뒤 경기와 랩 시간 측정을 시작합니다. 가속 키를 누르고 있으면 바로 출발합니다.
- 카운트다운 중에도 일시정지·탭 전환 시 남은 시간이 멈추며, 재시작하면 대기 상태로 돌아가 다음 출발에 3부터 다시 셉니다. 출발선 바로 뒤에서 반시계 방향으로 출발합니다.
- 도로 위에서 16개 체크포인트를 순서대로 통과한 뒤 출발선을 넘으면 한 바퀴입니다. 미니맵의 밝은 점이 다음 체크포인트입니다.
- 잔디에서는 속도가 줄어듭니다. 잔디에서 체크포인트를 지나쳤다면 그 지점 이전으로 돌아와 도로 위에서 정상 방향으로 통과해야 합니다. 길을 잃었을 때는 R로 재시작할 수 있습니다.
- 세 바퀴를 마치면 주행이 멈추고 총 시간과 각 랩 기록을 표시합니다.
- 최고 기록은 **가장 빠른 한 바퀴의 시간**이며, 같은 브라우저와 주소의 `localStorage`에 저장합니다. 저장소 접근이 막히면 현재 실행 중에만 유지합니다.
- 벽, 나무, 건물은 배경 장식이며 충돌 판정은 없습니다. 모바일 터치 조작은 지원하지 않습니다.

## 구성

- `index.html`: 화면, HUD, 결과·일시정지 창, CSS 및 CDN import map.
- `main.js`: 장면, 자동차, 키 입력, 고정 간격 주행 시뮬레이션, 추적 카메라, 미니맵, UI.
- `race.js`: 트랙 설정·경계, 순차 체크포인트, 경기 상태, 시간·최고 기록 관리. 렌더링과 독립적입니다.
- `tests/race.test.mjs`: 정상 완주, 역주행·지름길 방지, 타이밍, 재시작·기록 저장 검증.

## 검증

Node.js 22 이상에서 의존성 설치 없이 로직 테스트를 실행할 수 있습니다.

```sh
node --test tests/race.test.mjs
```

브라우저에서는 다음을 확인합니다.

1. 콘솔 오류 없이 트랙·차량·기록 표시가 보이고, 창 크기를 바꿔도 화면 비율이 맞는지 확인합니다.
2. WASD와 방향키로 가속·브레이크·조향하고, 정지 시 제자리 회전이 없으며 키를 놓으면 감속하는지 확인합니다.
3. 잔디 진입 후 감속하고 도로로 복귀하면 가속 성능이 돌아오는지 확인합니다.
4. 커브에서도 카메라가 차 뒤를 따라가고 앞쪽 도로가 보이는지 확인합니다.
5. 출발선 왕복·역주행·잔디 지름길로 바퀴가 올라가지 않고, 정상 완주 시 랩 타임이 갱신되는지 확인합니다.
6. 일시정지·탭 전환 중 시간과 자동차가 멈추고, 재개 시 입력이 눌린 채 유지되지 않는지 확인합니다.
7. 정확히 세 바퀴에 경기가 끝나고, 재시작·새로고침 후에도 최고 기록이 남는지 확인합니다.
8. W와 ↑ 각각으로 출발할 때 중앙에 3 → 2 → 1이 순서대로 표시되고, 가속·브레이크·조향 키를 눌러도 카운트다운 중 차량 위치·방향·속도와 랩 타이머가 그대로인지 확인합니다.
9. 카운트다운 중 일시정지·탭 전환·재시작을 시험하고, 키를 짧게 눌렀다 놓아도 카운트다운이 끝나며 출발 뒤에는 정상 조작되는지 확인합니다.
