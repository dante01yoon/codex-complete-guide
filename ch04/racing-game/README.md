# OVAL — 브라우저 3D 레이싱

타원형 트랙에서 3바퀴를 달리는 싱글 플레이어 타임 어택입니다. Three.js 0.180.0을 jsDelivr CDN에서 불러오며, 빌드나 패키지 설치가 필요 없습니다.

## 실행

이 폴더에서 아래 명령을 실행하고 `http://localhost:8000`에 접속하세요.

```sh
python3 -m http.server 8000
```

ES 모듈을 사용하므로 `index.html`을 파일로 직접 여는 대신 HTTP 서버로 접속해야 합니다. CDN 로딩을 위해 인터넷 연결이 필요합니다. WebGL을 지원하는 최신 데스크톱 Chrome 또는 Firefox와 키보드를 사용하세요.

## 조작과 경기 규칙

| 입력 | 동작 |
| --- | --- |
| W / ↑ | 가속 |
| S / ↓ | 브레이크, 정지까지 감속 |
| A / ← | 좌회전 |
| D / → | 우회전 |
| Esc | 일시정지 / 계속 |
| 화면의 재시작 버튼 | 기록을 유지하고 새 경기 시작 |

- 시작 버튼을 누르면 타이머가 시작됩니다. 출발선의 화살표 방향으로 달리세요.
- 도로 밖에서는 속도가 줄어듭니다. 정지 상태에서 회전하거나 후진하지 않습니다.
- 도로 위에서 체크포인트 세 곳과 출발선을 순서대로 정방향 통과해야 한 바퀴로 인정합니다.
- 트랙을 벗어나면 현재 랩이 무효가 됩니다. 도로로 돌아와 출발선을 정방향 통과하면 새 유효 랩을 시작합니다. 무효 주행에 걸린 시간도 현재 랩과 총시간에 포함됩니다.
- 3바퀴를 완주하면 차량과 타이머가 멈추고 각 랩 시간과 총시간을 보여줍니다.
- 최고 랩은 유효 랩 완료 시, 최고 완주 기록은 3바퀴 완료 시 갱신합니다. 기록은 같은 브라우저와 사이트 주소의 `localStorage`에 저장됩니다. 저장이 차단되면 현재 세션에서만 유지됩니다.
- 다른 탭으로 이동하면 차량과 타이머가 일시정지합니다. 돌아온 뒤 계속 달리기를 누르세요.
- 오른쪽 위 미니맵에 실제 트랙 윤곽, 출발선과 내 차의 위치·진행 방향을 표시합니다. 트랙에서 멀어지면 지도를 축소해 차량이 계속 보이도록 합니다.

## 구성과 검증

### 자동 주행 테스트

`http://localhost:8000/?autopilot=1`을 열고 **레이스 시작**을 누르면 차량이 트랙 중앙선을 따라 자동으로 3바퀴 주행합니다. 카메라·미니맵·랩 판정은 기존 화면을 사용하며, 일시정지·계속·재시작도 가능합니다. 테스트 모드는 최고 기록을 읽거나 저장하지 않습니다. 쿼리가 없거나 값이 `1`이 아니면 기존 키보드 게임이 실행됩니다. 중앙선 좌표를 따라 이동하는 화면 검증용 모드이므로 키보드 조향이나 트랙 이탈 감속 검증에는 사용하지 않습니다.

- `index.html`: UI, 스타일, CDN import map, 초기화 오류 안내.
- `main.js`: Three.js 장면, 120Hz 고정 간격 업데이트, 추적 카메라, HUD와 경기 화면.
- `track.js`: 트랙 도형, 도로 판정, 방향을 확인하는 체크포인트 교차 판정.
- `car.js`: 차량 도형, 키보드 입력, 가감속·조향·잔디 감속.
- `race.js`: 경기 상태, 랩·시간 판정, 최고 기록 저장.
- `autopilot.js`: 명시적 쿼리 활성화와 중앙선 자동 주행.

로직 테스트는 Node.js 22 이상에서 실행할 수 있습니다.

```sh
node --test tests/*.test.mjs
```

브라우저에서는 방향키와 WASD 주행, 커브에서 카메라 추적, 트랙 이탈과 복귀, 출발선 왕복·역주행, 3바퀴 완주, 새로고침 후 기록 복원, 재시작, 창 크기 변경과 탭 전환을 확인하세요.
