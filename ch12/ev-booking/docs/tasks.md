# 서울 전기차 충전소 가상 예약 서비스 — 구현 작업 목록

- 작성일: 2026-10-05
- 근거: [prd.md](prd.md), [acceptance.md](acceptance.md)
- 상태: 계획 초안. 아래 구현 작업은 모두 미착수이며 기능 검증은 `NOT_RUN`이다.
- 각 T 작업은 한 번의 요청에서 하나의 모듈 또는 화면과 그 범위의 검증까지 마치는 단위이다. 서비스 전체 구현을 한 작업에 포함하지 않는다.
- `선행`의 T 번호는 먼저 완료할 작업, C 번호는 아래 확인 목록의 사용자 답변과 관련 문서 갱신이 먼저 필요한 항목이다. C 답변이 없는 작업은 시작하지 않는다. 미정 정책과 무관한 작업은 진행할 수 있다.
- 관련 AC는 추적 대상이다. 공통 기반이나 로직 작업만 끝났다고 해당 AC의 화면·실제 테스트 결제까지 통과한 것으로 보고하지 않는다.
- 금액·경계·권한은 원문 AC를 따른다. 본 목록은 새로운 제품 정책을 확정하지 않는다.

## 9. 작업 완료와 기록 방법

- 실행 요청 예: `T-22를 구현해 줘. 선행 조건을 확인하고 관련 AC 경계값을 검증해 줘.`
- 시작 시 세 문서와 해당 T·C·US·AC를 읽고, 선행 작업의 실제 완료 근거를 확인한다. 목록에 번호가 있다는 이유만으로 선행 작업이 끝났다고 간주하지 않는다.
- 완료 시 해당 행의 범위·완료 조건을 확인하고 변경 파일, 검증한 AC와 결과를 기록한다. 부분 작업의 검증을 전체 AC 통과로 확대하지 않는다.
- 검증 상태는 `PASS / FAIL / BLOCKED / NOT_RUN`을 구분한다. 특히 모의 결제 통과가 토스 테스트 실연결 통과를 뜻하지 않는다.
- C 항목 때문에 진행할 수 없으면 영향을 받는 작업과 질문을 명시한다. 새로운 정책을 임의로 보완하지 않는다.
- 이 목록 작성 자체는 구현 완료가 아니다. 코드 작성·실제 결제·배포는 이번 요청 범위에 포함하지 않는다.
