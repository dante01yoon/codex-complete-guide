## [실습 12] 03단계 정책 질문에 답하고 PRD 초안 요청

```text
답할게. 1) 학습용 시연 서비스야. 실제 서울 충전소 데이터 위에 만든 가상 예약 서비스이고 배포하지 않아. 2) 운전자의 헛걸음과 노쇼를 줄이는 게 목표야. 예약 이행률과 노쇼율로 판단해. 3) 일반 운전자 대상이고, 이용 제한이 없고 삭제되지 않은 충전기만 예약할 수 있어. 4) 특정 충전기의 이용 시간을 예약해. 주차면과 충전량은 보장하지 않아. 5) 지금부터 7일 이내, 30분 단위, 한 번에 30분부터 90분까지. 6) 즉시 확정, 한 사람당 진행 중인 예약은 1건, 시연은 테스트 계정으로 로그인. 7) 예약할 때 예약금 3,000원을 걸어. 시작 2시간 전까지 취소하면 전액 환불, 2시간 전부터 30분 전까지는 50% 환불, 30분 이내 취소와 노쇼는 환불하지 않아. 시작 후 15분 안에 체크인하지 않으면 노쇼로 처리하고 예약을 취소해. 8) 시연에서는 체크인 버튼과 이용 종료 버튼으로 확인해. 초과 이용 처리는 다음 버전. 9) 운영자가 점검이나 고장으로 예약을 취소하면 예약금은 전액 환불해. 10) 저장된 파일과 수집 시각을 보여 주고, 고장·점검·상태 확인 불가 충전기는 예약을 막아. 11) 예약금만 앱에서 결제하고 토스페이먼츠 테스트 모드를 써. 충전비는 현장 결제, 알림은 화면 안에서만. 12) 운영자는 담당 충전소의 예약 목록을 보고, 충전기를 점검 중으로 막고, 예약을 취소할 수 있어. 13) 모바일 웹. 같은 시간에 대기 신청을 받아 두고, 예약이 취소되거나 노쇼가 나면 첫 번째 대기자에게 자동으로 넘겨 줘. 실제 결제, 차량 자동 판별, 충전기 원격 제어는 하지 않아. 이 답을 반영해서 docs/prd.md에 PRD 초안을 써 줘. 배경과 문제, 목표와 성공 지표, 대상 사용자, 범위와 범위 밖, 유저 스토리(US-01처럼 번호), 열린 질문을 넣어 줘. 수용 기준은 다음 단계에서 따로 쓸 거야
```

## [실습 12] 04단계 열린 질문에 답하고 수용 기준 요청

```text
열린 질문에 답할게. 1) 정상 이용하면 이용 종료 때 예약금을 전액 돌려줘. 종료 버튼을 안 누르면 예약 종료 시각에 자동 종료하고 돌려줘. 2) 대기 신청할 때는 결제하지 않아. 승계되면 결제를 요청하고 10분 안에 결제하지 않으면 다음 대기자에게 넘겨. 3) 진행 중 예약은 결제 완료부터 이용 종료나 취소 전까지야. 대기 신청은 진행 중 예약과 별도로 1건까지 가능해. 4) 대기는 같은 충전기의 시작·종료 시각이 정확히 같은 예약에만 붙고, 신청 시각 순서로 줄을 세워. 5) 노쇼 뒤 승계하면 종료 시각은 그대로 두고 남은 시간만 이용해. 남은 시간이 30분 미만이면 승계하지 않아. 6) 승계 예약의 체크인 기한은 승계 확정 시각부터 15분이고, 취소 환불은 원래 시작 시각 기준 일반 규칙을 따라. 승계자도 노쇼면 다시 다음 대기자에게 넘겨. 7) 운영자 취소 때는 승계하지 않고 대기 신청도 함께 취소해. 8) 점검 차단해도 기존 예약은 운영자가 하나씩 취소해. 차단 해제는 포함하되 데이터상 고장·상태 확인 불가는 해제할 수 없어. 9) 정확히 2시간 전은 전액, 정확히 30분 전은 50%야. 체크인은 시작 후 15분 미만까지만 되고, 정확히 15분이 되면 노쇼야. 시작 후 사용자가 취소하면 환불 없음. 10) 7일 제한은 시작 시각 기준, 서울 시간, 매시 00분과 30분 시작. 이용시간 안내가 24시간인 충전기만 예약 대상으로 해. 11) 저장된 상태가 충전중이어도 미래 예약은 허용해. 체크인은 시작 10분 전부터 가능해. 12) 결제 승인을 확인하면 예약을 확정하고, 결제창이 열린 동안 10분간 그 시간을 임시로 잡아 둬. 같은 결제가 두 번 처리되지 않게 하고, 결제 후 자리 확보에 실패하면 전액 환불해. 13) 이행은 체크인 기준이고, 사용자 취소와 운영자 취소는 분모에서 빼. 목표치는 두지 않아. 14) 운전자 테스트 계정 3개, 운영자 1개, 담당 충전소 1곳. 시간 경과를 보여 줄 시연용 시계가 필요해. 이 답을 PRD에 반영하고, docs/acceptance.md에 유저 스토리별 수용 기준을 GIVEN/WHEN/THEN 형식으로 써 줘. 기준마다 AC-07-1처럼 번호를 붙이고, 금액과 경계 시각은 숫자로 정확히 적어 줘
```
