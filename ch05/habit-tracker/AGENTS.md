# 습관 트래커 작업 기준

## 필수 규칙

1. 화면 문구와 사용자에게 제공하는 설명은 한국어로 쓴다.
2. 외부 라이브러리 없이 HTML, CSS, JavaScript만 사용한다. 프레임워크, 외부 CDN, 외부 라이브러리 의존성을 추가하지 않는다.
3. 연속 실천 일수 등 날짜 계산 로직은 화면·DOM 처리와 별도 파일로 분리한다. Node.js 내장 테스트 러너인 `node --test`로 테스트하며, 외부 테스트 라이브러리는 사용하지 않는다.
4. 작업을 마치면 실제 실행한 테스트와 직접 확인하지 못한 항목을 구분해 보고한다. 실행하지 않은 검사나 브라우저 확인을 통과했다고 표현하지 않는다.

## 앱의 목적과 범위

- 혼자 사용하는 한국어 습관 트래커 웹앱을 만든다.
- 로그인 없이 한 브라우저에서 사용하며, 기록은 `localStorage`에 저장한다. 새로고침과 브라우저 재실행 후에도 기록을 유지한다.
- 첫 버전에서는 로그인, 기기 간 동기화, 배포, 백업·복원, 메모를 제외한다.
- 모든 습관은 매일 실천하는 목표로 취급하며, 횟수·분량 대신 완료 여부만 기록한다.

## 필요한 기능

### 습관 관리

- 습관을 추가하고 이름을 수정할 수 있다.
- 삭제 전 확인을 받고, 삭제하면 해당 습관의 기록도 함께 삭제한다.

### 날짜별 기록

- 습관 등록일부터 오늘까지 날짜별 완료 체크와 취소를 허용한다.
- 등록 전 날짜와 미래 날짜에는 기록할 수 없다.
- 날짜는 사용하는 기기의 현지 날짜를 기준으로 계산한다.
- 기록 변경은 저장하고, 연속 실천 일수와 히트맵에 즉시 반영한다.

### 연속 실천 일수

- 오늘 완료했다면 오늘을 포함해 연속으로 완료한 날짜 수를 표시한다.
- 오늘 아직 완료하지 않았다면 어제까지 이어진 연속 실천 일수를 표시한다.
- 오늘과 어제 모두 미완료라면 0일로 표시한다.
- 과거 기록을 수정하면 연속 실천 일수를 다시 계산한다.

### 히트맵

- 습관별로 최근 12주의 날짜별 기록을 보여 준다.
- 완료와 미완료를 색으로 구분하고, 등록 전 날짜는 별도로 표시한다.

## 완성 기준과 검증

- 실제 브라우저에서 추가, 체크, 취소, 이름 수정, 삭제가 정상 동작하는지 확인한다.
- 새로고침과 브라우저 재실행 후 기록이 유지되는지 확인한다.
- 과거 기록 수정이 연속 실천 일수와 히트맵에 즉시 반영되는지 확인한다.
- 날짜가 바뀌면 오늘 날짜와 연속 실천 일수가 정확하게 갱신되는지 확인한다.
- 모바일과 PC 화면에서 잘림 없이 주요 기능을 사용할 수 있는지 확인한다.
- 날짜 계산 테스트에는 기록 없음, 오늘 완료, 오늘 미완료·어제 완료, 오늘·어제 미완료, 중간 누락, 과거 기록 수정, 월말·연말·윤년 경계를 포함한다.
- 테스트 결과는 실행 명령과 함께 PASS 또는 FAIL로 보고한다. 직접 확인하지 못한 항목은 NOT_RUN으로, 환경이나 권한 때문에 막힌 항목은 BLOCKED로 구분하고 이유를 적는다.
- 자동 테스트 결과와 실제 브라우저 확인 결과는 별도로 보고한다.
