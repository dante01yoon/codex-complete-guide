# 하루 한 칸

외부 라이브러리 없이 HTML, CSS, JavaScript로 만든 한국어 습관 트래커입니다.

## 실행

Node.js 20 이상에서 프로젝트 폴더에서 실행합니다. 별도 설치는 필요하지 않습니다.

```sh
node server.mjs
```

브라우저에서 <http://127.0.0.1:5173>을 엽니다. 종료는 터미널에서 `Ctrl+C`를 누릅니다. JavaScript 모듈을 사용하므로 HTML 파일을 직접 열지 말고 서버로 실행합니다.

## 사용

- 상단의 ‘화면 테마’에서 시스템·라이트·다크를 선택합니다. 처음에는 시스템 설정을 따르고, 선택은 습관 기록과 별도로 이 브라우저에 저장됩니다.
- 시스템을 선택한 동안에는 운영체제의 밝은 화면·어두운 화면 변경을 반영합니다. 라이트·다크를 직접 선택하면 시스템 설정보다 우선합니다.
- 테마 설정 저장이 차단돼도 현재 화면의 전환은 가능하며, 설정 유지에 관한 안내가 표시됩니다.
- 습관을 추가하고 왼쪽 체크 버튼으로 오늘의 실천을 기록합니다.
- 연속 일수는 오늘 완료 시 오늘부터, 미완료 시 어제부터 거슬러 계산합니다.
- 히트맵은 월요일 시작, 이번 주를 포함한 최근 12개 달력 주입니다. 이번 주의 미래 날짜는 체크할 수 없습니다.
- 히트맵의 날짜 칸을 누르거나 ‘지난 기록’에서 날짜를 선택해 완료 체크·취소합니다. 등록일부터 오늘까지만 수정할 수 있습니다.
- 습관 이름을 수정하거나 삭제할 수 있습니다. 삭제 확인을 마치면 해당 기록도 삭제됩니다.
- 현지 날짜를 사용하며, 열린 화면은 15초마다 또는 다시 화면으로 돌아왔을 때 날짜 변경을 반영합니다.
- 기록은 이 브라우저의 `localStorage`에 저장됩니다. 같은 주소·포트로 다시 열어야 같은 기록을 볼 수 있습니다. 시크릿 모드, 브라우저 데이터 삭제, 다른 기기·브라우저에서는 기록 유지가 보장되지 않습니다.

## 테스트

```sh
node --test
```

날짜 계산은 `dates.mjs`, 저장 데이터 검증과 기록 변경은 `model.mjs`, 화면 처리는 `app.mjs`에 분리돼 있습니다. `theme.js`는 스타일시트보다 먼저 테마를 적용합니다. 테마 테스트에는 설정 복원·시스템 변경·저장 실패·습관 데이터 보존과 주요 색상 대비 검사가 포함돼 있습니다. 모든 테스트는 Node.js 내장 기능만 사용합니다. 실제 브라우저 확인 결과는 `VERIFICATION.md`에 별도로 기록합니다.
