# 결제 시연 구현 계획

사용자 승인: Node HTTP + HTML, 로컬 파일 저장, 5180, 원본 충전소 자동 선택,
환불 실패 시 운영자 확인 필요. 이번 시연의 통합 테스트는 화면 확인으로 대체한다.
기존 규칙 테스트·훅·헌법 전역 설정은 변경하지 않는다.

- [x] `src/rules/demo-order.ts`: 원본의 명확한 24시간·DC콤보·제한 없음·유효 상태 후보와 미래 60분 구간 선택.
- [x] `src/demo/server.ts`: 루프백 HTTP, 단일 시연 운전자 공유 주문, 파일 저장, 승인 직렬화,
  기존 금액 검증·승인 reducer 호출, 전액 보상 환불 1회와 실패/불명 상태 저장.
- [x] `src/demo/public/`: 주문 요약, 토스 v2 위젯, 카드 선택 검사, 승인 및 결과 화면.
- [x] `package.json`: `demo:payment` 실행 명령.
- [x] 구문·타입 검사 후 5180 시작. 브라우저에서 주문·위젯·카드 창·미완료 결과 화면 확인.
- [x] 검증 범위·실제 API 호출 여부·실행 방법 기록. 실제 승인·환불 완료는 NOT_RUN.

확인 중점: 금액 조작은 승인 전 차단, 새로고침으로 중복 승인/환불 없음,
응답 불명은 성공으로 표시하지 않음, 시크릿/원문 응답 비노출, 모바일 가로 넘침 없음.
