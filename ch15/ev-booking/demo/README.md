# 루프 실행 기록 화면

15장에서 실행한 `artifacts/loops`의 기록을 읽는 로컬 전용 도구입니다.

## 실행

```sh
node demo/server.mjs
```

브라우저에서 http://127.0.0.1:5181 을 엽니다. 종료는 서버 터미널에서 Ctrl+C.
다른 포트가 필요하면 `PORT=5182 node demo/server.mjs`로 실행합니다.
추가 패키지를 설치하지 않습니다. 서버는 루프백 주소에서만 실행합니다.

## 승인된 설계

- 왼쪽에 루프 목록, 오른쪽에 선택한 루프의 시작 전 검사 → 바퀴별 결과 → 종료 타임라인.
- 실패 수 변화, PASS / FAIL / BLOCKED / NOT_RUN, 소요 시간, 종료 이유를 표시합니다.
- 실패 사례와 원문 JSON을 펼쳐 볼 수 있습니다.
- 최신 루프를 기본 선택하며 기록 새로고침으로 디스크의 최신 기록을 읽습니다.
- 실행 기록 시각은 서울 시간으로 명시합니다. 기록이 없는 값은 추정하지 않습니다.
- `demo` 밖의 제품 코드·테스트·정책·훅·기존 기록은 수정하지 않습니다.

## 구현 계획

**Goal:** 실제 루프 기록을 바탕으로 진행과 종료 근거를 한 화면에서 확인합니다.

**Architecture:** Node.js 24 HTTP 서버가 JSON 기록을 읽어 브라우저에 제공합니다.
별도 프레임워크 없이 HTML·CSS·JavaScript로 목록과 타임라인을 렌더링합니다.

**Tech Stack:** Node.js 24, HTML, CSS, JavaScript (추가 의존성 없음).

**Spec:** 위 승인된 설계. 사용자의 화면 구성 승인에 따라 현재 대화에서 직접 구현합니다.

### 작업과 파일

- [x] `records.mjs`: 원본 JSON 읽기, 불완전 기록 경고, 비밀값 제거, 결과 집계.
- [x] `server.mjs`: 루프백 HTTP 서버, 읽기 전용 API, 허용된 화면 파일만 제공.
- [x] `index.html`, `styles.css`, `app.js`: 루프 목록, 선택 상세, 타임라인, 원문 펼치기.
- [x] 실제 6개 기록의 상태·바퀴·실패 수·종료 이유와 API 응답을 대조.
- [x] 데스크톱·모바일 표시와 루프 선택·원문 펼치기·새로고침을 브라우저에서 확인.
- [x] 완료 후 Codex 브라우저 패널에 화면 열기.

### 확인할 경우

- 바퀴 없이 종료된 루프에도 시작 전 검사와 종료 이유를 표시합니다.
- 에이전트 차단 후 실행되지 않은 검사는 NOT_RUN으로 표시합니다.
- 유효하지 않은 테스트 보고서의 빈 사례 배열을 0개 실패 또는 성공으로 간주하지 않습니다.
- summary가 없으면 종료 기록 없음으로 표시하고 저장된 바퀴까지만 보여 줍니다.
- 깨진 JSON·누락 파일·빈 기록은 안내하며 다른 정상 루프는 계속 표시합니다.
- 원문은 텍스트로 표시하며 HTML을 실행하지 않습니다.

이 도구는 저장된 실행 결과를 표시합니다. 새 루프 실행이나 제품 기능 검증을 수행하지 않습니다.
