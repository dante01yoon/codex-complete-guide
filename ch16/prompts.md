## 02 도구 계획과 테스트(새 채팅, `touch .codex/TEST_WRITING` 뒤)

```text
이 에이전트들로 기능을 하나 만들어 보자. '강남역 근처 DC콤보 충전기 7시에 30분 예약해 줘' 같은 말을 처리할 수 있게 MCP 도구 세 개가 필요해. 충전기 검색, 10분 임시 점유, 그리고 결제 링크 요청. 결제 링크는 사람이 승인했을 때만 만들어야 해. 그래프대로 계획이랑 테스트까지만 하고 확인받아 줘. 테스트 스위치는 켜 뒀어.
```

```text
읽기는 괜찮아, 계속해 줘. 7시는 오늘 저녁 7시, 근처는 반경 1km로 하고, 점유가 끝나면 결제 링크도 못 쓰게 해 줘.
```

## 03 사람 승인 방식

```text
승인은 이렇게 하자. 승인 전에는 결제 링크 대신 요약이랑 승인 명령을 돌려주고, 내가 터미널에서 npm run approve -- <holdId>를 실행하면 승인 파일이 생기게 해 줘. 그 파일이 있고 점유가 살아 있을 때만 결제 링크를 만들어. 승인 폴더는 내가 가드로 막아 놨어. 문서랑 테스트에 반영하고 멈춰.
```

