# 서울 충전소 3D 대시보드

2026-10-05 승인 시안을 구현한다. React + Vite, MapLibre GL, OpenFreeMap Liberty.
흰색 350px 사이드바, 밝은 회색 건물 지도, 민트/파랑/주황/회색 상태 색상을 유지한다.

- 충전소 ID + 충전기 ID로 상태를 결합한다. `statUpdDt`가 더 최신인 상태만 덮어쓴다.
- 상태 2: 충전대기, 3: 충전중, 4/5: 고장·점검, 1/9/기타: 확인 불가.
- 충전소별 하나의 정사각형 기둥에 상태별 구간을 누적한다. 충전기 1대 = 6m.
- 좌표가 확인되는 충전소만 지도에 표시한다. 전체 통계에는 모든 충전기를 포함한다.
- `data/dashboard.json`은 충전소 단위의 압축된 JSON이다. 브라우저는 이 파일만 읽는다.
- 서버는 `web`만 제공한다. 원본 2개와 `.env`는 웹 루트 밖에 둔다.
- 3D/2D 버튼은 카메라 기울기를 바꾸고, 서울 전체 버튼은 서울 경계로 이동한다.
- 기둥 클릭은 충전소명, 주소, 충전기 수, 상태별 개수를 팝업으로 보여준다.
- 모바일은 통계/범례 아래 지도를 배치한다.

시안과 의도적으로 다른 부분: 실제 OpenFreeMap 건물/지형/라벨을 사용하므로
생성 이미지의 지리적 배치와 기둥 위치는 재현하지 않는다. 저장 시각과 실시간이
아니라는 안내를 추가하여 데이터의 기준을 명확히 한다. 팝업은 원본 주소와
네 상태 모두를 보여준다.

검증: 병합의 최신/과거/중복, 네 상태 분류, 좌표 오류, 누적 기둥 높이와 총합,
프로덕션 빌드, 원본/인증키 비공개, 데스크톱/모바일, 팝업과 2D/3D/전체 이동.
